# BridalGlow — Bridal Services Platform

BridalGlow is a responsive frontend-only bridal service discovery and booking prototype created for internship task **WD-MAT-003**.

## Features
- Elegant bridal landing page with service categories
- Artist listing with text search, category/location filters, and sorting by price/rating
- Artist details, portfolio preview, sample reviews and ratings
- Demo booking form with service, date, time, package and notes
- User dashboard with demo booking history
- Favorites/wishlist
- Simulated login/register
- Dark mode toggle
- Responsive desktop, tablet, and mobile layout
- Demo data persistence using browser `localStorage`

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript
- Browser localStorage

## Run locally
1. Extract the ZIP.
2. Open the `BridalGlow` folder.
3. Double-click `index.html` to open it in a modern browser.

No build step, API key, or database is required. Google Fonts and remote Unsplash images need an internet connection; the core layout and interactions are local.

## Deploy
Upload `index.html`, `style.css`, `script.js`, and `README.md` to a public GitHub repository. For GitHub Pages, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, and save.

## Important prototype notes
- Authentication is simulated in the browser and is not secure.
- Booking and review flows are demonstrations only; no real artist is contacted and no payment is processed.
- Sample artist profiles, prices, ratings, reviews and portfolio visuals are fictional/example data.
- Browser localStorage is local to the browser profile and is not a shared database.
- Do not use real passwords or sensitive personal information.
